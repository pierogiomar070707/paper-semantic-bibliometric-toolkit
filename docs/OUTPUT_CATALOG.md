# Output Catalog

- `outputs/00_*`: environment and search metadata.
- `outputs/01_*`: field coverage, duplicates, DOI, year and corpus validation.
- `outputs/02_*`: cleaned corpus, source normalization, affiliation and institution candidates.
- `outputs/03_*`: Author/Index Keyword tables and co-occurrence edge lists.
- `outputs/04_*`: domain themes, matched documents, n-grams, models, datasets and gap indicators.
- `outputs/05_*`: annual production, keyword and theme trends, emerging terms.
- `outputs/06_*`: sources, authors, institutions, countries and collaboration edges.
- `outputs/07_*`: citations, reviews, Related Work candidates and semantic-gap papers.
- `outputs/08_*`: RIS status.
- `thesaurus/`: VOSviewer thesauri and keyword-selection audits.
- `figures/`: PNG, PDF and SVG figures.
- `reports/`: methodology text, evidence report, captions and manuscript integration guide.
- `validation/`: pipeline execution log, output manifest and final QA.
